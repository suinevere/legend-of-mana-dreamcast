# ram_map.txt: Ring Ring Land's RAM, one field per line, for pocketstation/tools/gen_ram.py.
# <PocketStation addr> <u8|s8|u16|s16|u32>[<count>] <name> <VMU addr|-> <description>
# unk_ fields are bases R1's headers name; the batches rename and resize them as the rewrite learns what they hold.
0x12C u8 unk_12C - kernel word read by 020045F0, 02004706
0x200 u8 unk_200 - read by 02000400
0x204 u8 docked - nonzero after the line-10 (dock) interrupt; sounds are skipped and 02000440 shows the kernel's dock screen while set
0x208 u32[13] irq_handler - interrupt handlers by line; 02002B88 calls slot n for interrupt bit n
0x23C u32 fiq_driver - routine the FIQ callback jumps to after acknowledging Timer 2; 0 runs the interrupt dispatch instead
0x240 u32[32] fb - frame buffer, one word per row, copied to the LCD each frame
0x2C0 u32[32] blit_a - the blitter's first shifted copy of a sprite
0x340 u32[32] blit_b - the blitter's second shifted copy (masks)
0x3C0 u32 com_flags - address of the kernel's communication flags from SWI 6; bit 0 set skips sounds, bit 8 ends the main loop
0x3C4 u16 seed - random seed: seed = (seed + 1) * 0x3D09 per draw
0x3C6 u8 btn_prev - buttons held at the last read
0x3C7 u8 btn_new - buttons newly pressed at the last read
0x3C8 u8 btn_press - new presses plus auto-repeats at the last read
0x3C9 u8 btn_latch - buttons the interrupt saw pressed since the last read
0x3CA u8 hold_reload - frames of fire hold that count as a long hold
0x3CB u8 hold_count - frames left of the current long fire hold
0x3CD u8 repeat_up - auto-repeat countdown for up
0x3CE u8 repeat_down - auto-repeat countdown for down
0x3CF u8 repeat_left - auto-repeat countdown for left
0x3D0 u8 repeat_right - auto-repeat countdown for right
0x3D4 u8 mode - current game mode; mode handlers are tabled at 0x020084B4
0x3D5 u8 mode_phase - step within the current mode
0x3D6 u8 mode_wait - frames the current mode waits
0x3D8 u8 mode_done - set when a mode has finished; also the three-way menu cursor 02002416 moves, and the phase 02001E42 steps through 0-3
0x3D9 u8 scene_id - set to 0x5E when the board starts; other modes test it; 02001E42 counts it down as a frame wait
0x3DA u8 scratch_wait - shared byte: 0xFF makes 02001F28 start its scroll at 0x68; 02002AE4 and 02002464 set a 20-frame countdown here; 02000614 reads 0x3DA-0x3DB as a signed halfword
0x3DB u8 scratch_kinds - shared byte: one bit per item kind (low byte of the item's 0x02008094 entry) in the list for 02002D22; the lowest of the three symbols 02004566 picks; the first reel's next symbol from 0200225C; a scroll frame from 02001E42
0x3DC u8 scratch_first - shared byte: lowest kind in scratch_kinds for 02002D22; the middle symbol 02004566 picks; the second reel's next symbol from 0200225C; 0200448A writes 0x40 here as a halfword with scratch_count; 02001F28 scrolls it up to 0x68
0x3DD u8 scratch_count - shared count: the item of kind scratch_first 02002D8A looks for (0 the first), a frame countdown in 02001F28, the payout kind 0200234C reads, a shown count in 02000CA4; the highest symbol 02004566 picks; 02001E42 scrolls 0x3DC-0x3DD as a signed halfword
0x3DE u8 bag_nth_index - list index of that item
0x3DF u8 bag_kind_count - distinct kinds in the list
0x3E0 u8 scratch_lo - low byte of a shared halfword that 0200234C writes with the payout and 02000AF8 reads whole; 02001008 reads it as a signed byte; 02002D64 counts items of kind scratch_first into it
0x3E1 u8 scratch_hi - high byte of that halfword; 02001008 reads it as a signed byte
0x3E2 u8 bag_full - set when the item list fills
0x3E3 u8 cycle16 - counter stepping 16 down to 1 each frame
0x3E4 u8 odds_set - mode sub-state byte 0; picks the weight set at 0x02009EEC
0x3E5 u8 steps - cells walked; reaching (odds_set + 1) * 32 ends the lap
0x3E6 u8 walk_behind - cells walked back from steps; forward steps retrace them before counting new cells
0x3E8 u8 sel_a - mode sub-state byte 4
0x3E9 u8 sel_b - mode sub-state byte 5
0x3EA u8 sel_c - mode sub-state byte 6
0x3EB u8 sel_d - mode sub-state byte 7
0x3EC u8 cell_saved - sel_c as the board started
0x3ED u8 facing_saved - sel_d as the board started
0x3EE u8 sel_e - mode sub-state byte 10
0x3EF u8 walk_busy - set while a step round the ring animates
0x3F0 u8 walk_frame - frame of the running step
0x3F1 u8 walk_kind - running step: 0 forward a cell, 1 back a cell, 2 the opening count up to 12, above 2 a count down
0x3F2 u8 bonus_done - set when a 0x10 cell or the lap's end on odds set 2 starts bonus scene 13
0x3F4 u8 meter_max - meter a refill cell restores; a refill at full raises it by one up to 9
0x3F5 u8 meter_shown - meter value on show, catching up with meter
0x3F6 u8 meter - meter value; reaching 0 on show ends in mode 12
0x3F7 u8 meter_delay - frames counted up to 30 (40 at meter 0) before meter_shown takes meter; left at the limit after
0x3F8 u8 walk_back - set while the pending steps walk backwards; walk_kind takes it XOR sel_b
0x3F9 u8 walk_left - steps still to walk on their own, one started each time the last ends
0x3FA u8 step_result - how the last step ended: 0 nothing to do, 1 an ordinary step, 2 keeps a refill cell from refilling, 3 the lap's last step
0x3FC u8 bag_cursor - cursor into the item list
0x3FE u16 lap_points - points won this lap: 0200284A clears it at the lap start and 0200234C adds each payout
0x404 u8 reel_phase - reel spin step: 0 speeding up, 1 full speed, 2 slowing, 3 stopping, 4 stopped
0x405 u8 reel_count - reel layout: 3 when the reels load, 4 from 0200448A, 5 from 020044B6
0x406 u8 reel_slide - 0200153C draws the reel window at y = reel_slide - 12 while reel_phase is 0 or 7; 02004354 clears it
0x408 u8 lap_mark - cleared at each lap start and by a refill cell; 020044B6 raises strip symbols by it
0x409 u8 reel_len - symbols on a reel strip; reel positions wrap at reel_len * 0x200
0x40A u8 reel_len_b - symbols on the second reel's strip, as 0200225C reads it
0x40B u8 strip_c_len - symbols 0200284A loads into strip_c; 020044B6 copies that many into strip_a
0x40C u16 reel_speed_a - first reel's speed, added to reel_pos_a each frame
0x40E u16 reel_speed_b - second reel's speed, added to reel_pos_b each frame
0x410 u16 reel_pos_a - first reel's position, 0x200 per symbol; the board's random stops (02004532) and symbol lookups (0200454A) count 0x280 per symbol
0x412 u16 reel_pos_b - second reel's position, 0x200 per symbol; the board's random stops (02004532) and symbol lookups (0200454A) count 0x280 per symbol
0x414 u16 reel_speed_c - third reel's speed, added to reel_pos_c each frame
0x416 u16 reel_pos_c - third reel's position, 0x200 per symbol
0x424 u8[16] marker - four marker slots of four bytes: object type (0xFF free), frame, frames left on it, signed x offset
0x434 u8[40] anim - ten animation slots of four bytes: id (0xFF free), argument (for ids 8 and up but 0x16, bit 0 two frames on and bit 1 mirrored), frame toggle, timer
0x484 u8[32] cell_arg - each board cell's argument by sel_c: a scene, a meter step or 0 for a refill
0x4A4 u8[32] cell_type - each board cell's type by sel_c: 2-4 scenes, 0x10 the bonus, 0xFF the argument's event, others a choice
0x4C4 u32 points - points total, capped at 99999 by 0200234C; the first word of the saved state block
0x4C8 u32 bag_count - items in the list
0x4CC u8[51] bag_items - item ids, oldest first
0x500 u8 unk_500 - base 0x4F4 + 0xC, used by 0200284A, 020029EC, 02003EA4
0x501 u8 payout_unit - points one payout step is worth; 0200234C multiplies it by the reel result and the laps walked
0x502 u8 board_steps - how many of board_arg_set's lowest args 02003EA4 puts on every fourth cell
0x503 u8 board_args - args 02003EA4 places in all; those past board_steps go on even cells, by odds once the free cells run short
0x504 u32 board_arg_set - bit n offers cell arg n + 1 to 02003EA4
0x508 u8[20] board_arg_kinds - by cell arg 7-26: choice kinds such a cell may become in 02003EA4, one bit each
0x544 u8[16] strip_a - first reel's symbol strip, loaded from strip 0; strip 3 from 0200448A, strip_c raised by lap_mark from 020044B6
0x554 u8[16] strip_b - second reel's symbol strip, loaded from strip 1
0x564 u8[16] strip_c - third reel's symbol strip, loaded from strip 2
0x5C4 u32 snd_start - address of the playing sound's samples (the reference traces zero 0x5C4-0x5D1)
0x5C8 u32 snd_pos - next sample index
0x5CC u32 snd_len - samples in the playing sound
0x5D0 u8 snd_playing - id of the playing sound, 0xFF for none
0x5D1 u8 snd_next - id queued to play next, 0xFF for none
0x5D2 u8 sound_req - request byte for the sound driver
0x5D3 u8 snd_mode - 1 when samples are signed bytes scaled into ten bits; 2 turns sound off
0x5D4 u8[6] ticks - three (count, seen) tick counter pairs; the timer callback advances count, the frame wait records seen
0x7A1 u8 unk_7A1 - read by 02000440
