# NAME FILE LEVEL ROUTINE|inlined:CALLER ARGS RESULT DESTROYS STATUS
# LEVEL: leaves at 0, a recursion group sharing one level, from vmu_callgraph.py levels.
# ROUTINE: the LC86K routine this function becomes, or inlined:CALLER (CALLER is * when inlined everywhere, as game.h's accessors are).
# ARGS: comma list of param=REG (ACC, B, C; TR for 16-bit TRH:TRL; TRB for 24-bit TRH:TRL:B, TRH highest; mem:NAME for wider or extra values), or -. The mem: arguments sit in game.inc's ARG_BLOCK (work RAM 0x1DB-0x1E7, vmu_ram 0x2DB-0x2E7, which no field uses) in ARGS order, each its C size (a pointer's pointee), little-endian; NAME only labels the slot. Change a row's mapping when its routine is written.
# RESULT: REG (ACC, TR, TRB), mem:NAME for a result in ARG_BLOCK after the mem: arguments, or over:NAME for one at ARG_BLOCK+0 over the value arguments, which the routine reads first (a struct is compared field by field), or - for void; a todo row's - may also stand for a result too wide for a register, until it is written.
# DESTROYS: comma list of registers the routine may destroy (ACC, B, C, TRH, TRL, PSW for its flags, R0-R3, VRMAD, FPR), or -, as its header lists them; PSW means its flags (CY, AC, OV) only, as the RAM and indirect bank bits must come back as they went in. vmu_harness --call poisons them with 0xA5 when it returns, the RESULT's registers excepted, and call_compare.py fails a routine that changes a register outside DESTROYS and RESULT. Every todo routine carries the conservative default until it is written, and an inlined: row carries - (it is never CALLFd on its own).
